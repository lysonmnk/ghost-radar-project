📖 PANDUAN INVESTIGASI CERTAINTY FACTOR (CF)

🎯 Aturan Permainan Utama:

• Skala Grid: 1 level tunggal berukuran 4x4 (16 petak).
• Pergerakan Hantu: Hantu DIAM TOTAL (statis), ditentukan sekali saat game dimulai.
• Label Sumbu: Label KOLOM 0..3 di bagian atas dan BARIS 0..3 di samping kiri ditampilkan dengan kontras tinggi.

📊 Perhitungan CF Berdasarkan Grid Belum Dipilih:

• Nilai CF setiap grid dihitung hanya berdasarkan grid yang belum dipilih.
• Tidak ada lagi grid bernilai 0 di sekitar grid yang sudah dicek dan ternyata salah. Hanya grid yang dicek & salah yang dikunci ke 0.
• Grid yang belum dipilih memiliki nilai CF positif sesuai kumpulan dataset bukti yang terkumpul sampai iterasi saat ini.

🧠 Dataset & Arah Keberadaan Hantu:

• Dataset: Kumpulan data rekaman seluruh pemilihan grid beserta respons sensor.
• Arah Hantu: Pola sebaran nilai CF menunjukkan arah kemungkinan keberadaan hantu (seperti Barat Laut, Timur Laut, Tenggara, Barat Daya).
• Rumus kombinasi bukti: CF = CF1 + CF2 * (1 - CF1).

🔄 Game Baru:

• Setiap kali game baru dimulai, hantu ditempatkan di sel yang berbeda dari posisi game sebelumnya.
• Seluruh dataset direset, semua sel dikembalikan ke kondisi belum dipilih (base CF = 1/16 = 0.06).
